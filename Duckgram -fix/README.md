# Duckgram fix 

**Duckgram fix** — это механизм восстановления доступа к **web.telegram.org**, когда провайдер или сеть блокируют нагрузочные IP-адреса Telegram.

## О проекте

Этот проект является частью механизма **Duckgram fix**. Изначально это была работа другого разработчика, но она была **очень сильно модифицирована** и **продолжает развиваться**.

Вся логика основана на локальном правиле в системном файле `hosts`:

```
# duckgram
149.154.167.220 web.telegram.org
```

- Новые записи помечаются маркером `# duckgram`.
- Старые блоки помечались `# telegram-web-fix` — снимаются начисто при отключении.

## Состав проекта

| Файл | Назначение |
|------|------------|
| `duckgram.bat` | Основной скрипт: меню, UAC-админ, авто-настройка, установка/снятие правила |
| `duckgram-ip.cfg` | Текущий найденный рабочий IP |
| `build-exe.ps1` | Сборка `Duckgram.exe` (локально, через системный csc). Скрипт и исходник обязаны быть в UTF-8 c BOM |
| `Duckgram.exe` | Собранное приложение (полный аналог `.bat` в виде exe) |
| `utils\tg-hosts.ps1` | Работа с hosts: маркеры, снятие legacy-блоков |
| `utils\telegram-autodetect.ps1` | Автопоиск и запись рабочего IP в `duckgram-ip.cfg` |
| `utils\update-ip-candidates.ps1` | Обновление списка кандидатов IP (официальные подсети) |
| `utils\convert-cidr-to-candidates.ps1` | Конвертация CIDR-подсетей в кандидатов |
| `lists\telegram-ip-candidates.txt` | Кандидаты IP для проверки |
| `lists\telegram-ip-failed.txt` | IP, на которых проверка не прошла |
| `backup\hosts.backup` | Резервная копия hosts |

## Использование

Запусти `duckgram.bat` (или `Duckgram.exe`) **от администратора**.

Меню:
- `1` — установить fix (добавить правило в hosts)
- `2` — отключить fix (снять правило, включая legacy `# telegram-web-fix`)
- `3` — состояние (проверить текущее правило)
- `4` — автодетект IP через входящие соединения
- `5` — обновить список IP-кандидатов
- `6` — **авто-настройка**: сама находит рабочий IP и включает fix одним запуском
- `0` — выход

Скрытые (silent) режимы для автоматизации:
- `duckgram.bat enable-silent` — включить fix без меню (exit 0 при успехе)
- `duckgram.bat disable-silent` — отключить fix без меню

### Авто-настройка (пункт 6)

- Проверяет уже установленное правило и доступность `web.telegram.org`.
- Если всё работает — ничего не меняет, включая «умный» пропуск: при уже найденном списке кандидатов обновление не запускается (одна попытка ретрая).
- Если не работает — запускает автодетект, записывает рабочий IP в `duckgram-ip.cfg` и ставит правило в hosts.

## Сборка Duckgram.exe

```
powershell -NoProfile -ExecutionPolicy Bypass -File build-exe.ps1
```

Требования:
- Windows + .NET Framework 4.x (системный `csc.exe`).
- Никаких NuGet-пакетов и доступа в интернет не нужно.
- **Важно:** `build-exe.ps1` должен быть сохранён в UTF-8 с BOM, иначе PowerShell 5.1 / csc.exe читают файл в ANSI (CP1251) и кириллица в exe ломается.

При первом запуске `Duckgram.exe` может сработать эвристика антивируса (запуск C#-приложения + правка hosts + распаковка ресурсов в `%TEMP%\Duckgram\`). Это ложное срабатывание. Для сборки валидного exe используй `build-exe.ps1` или допилку; проверяй подпись через VirusTotal.

## Предупреждения

- Скрипты требуют **прав администратора**.
- Вносить правки в hosts следует осознанно; резервная копия снимается в `backup\hosts.backup`.
- Проект развивается: следи за обновлениями механизма Duckgram fix.

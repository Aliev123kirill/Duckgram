# Ссылки t.me в приложение

Расширение для Chrome, Яндекс Браузера, Edge, Opera и других Chromium-браузеров.
Перехватывает переходы на `https://t.me/...` и сразу открывает их в приложении
через `tg://`, не загружая страницу.

Подходит любому обработчику `tg://`: если в системе открывается Duckgram —
ссылка уйдёт в него, если обычный Telegram — в Telegram.

## Установка

### Яндекс Браузер (без режима разработчика)

1. Возьмите файл `tg-links-extension-1.0.0.crx` из папки `dist`.
2. Откройте в браузере страницу `browser://tune`.
3. Перетащите файл `.crx` в окно браузера и подтвердите установку.

Расширение появится в разделе **Из других источников** и останется включённым
после перезапуска браузера. Режим разработчика включать не нужно.

### Другие Chromium-браузеры (распакованная папка)

Chrome, Edge и Opera не принимают `.crx` из файла, поэтому у них остаётся
обычная установка через режим разработчика:

1. Откройте страницу расширений:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Opera: `opera://extensions`
2. Включите **Режим разработчика** (переключатель справа сверху).
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку.

### Первый переход

Откройте любую ссылку `https://t.me/...` — браузер спросит
«Открыть в приложении?». Поставьте галочку «Всегда разрешать» и подтвердите.
В следующем окне («собирается открыть это приложение») отметьте
«Запомнить выбор для таких ссылок» — тогда вопрос больше не появится.

После этого такие ссылки будут уходить в приложение без вопроса и без загрузки
страницы.

## Как это работает

`background.js` слушает начало навигации на домены `t.me` и `telegram.me`,
преобразует адрес в `tg://resolve?domain=...` (или `tg://join?invite=...`)
и переадресует вкладку на этот протокол. Дальше ссылку открывает приложение,
которое зарегистрировано в системе обработчиком `tg://`. Если обработчик
не зарегистрирован, браузер покажет запрос на выбор приложения.

Чтобы браузер вообще не начинал загрузку страницы (и не показывал ошибку,
если сайт недоступен), расширение при старте ставит правило `declarativeNetRequest`:
запрос на `t.me` подменяется внутренней страницей `open.html`, которая мгновенно
вызывает `tg://`. Сеть не используется, поэтому ожидания таймаута нет.

## Ограничения

- Работает только в Chromium-браузерах. Для Firefox нужен отдельный manifest.
- Ссылки вида `t.me/s/канал` (веб-версия канала) не перехватываются.
- Расширение не обращается к сети и ничего не передаёт: вся логика локальная.
